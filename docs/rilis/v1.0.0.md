# Catatan Rilis v1.0.0 — RPL Konter Sampit

**Tanggal:** 18 November 2026  
**Versi:** 1.0.0  
**Tag yang disarankan:** `v1.0.0` (belum dibuat oleh agen; perintah di bawah untuk pengguna)

## Ringkasan

Rilis pertama aplikasi konter: transaksi pulsa/data/token, penjualan dan pengelolaan voucher, voucher masuk, kasbon, riwayat/filter, laporan, autentikasi dua peran, dan pengamanan dasar.

## Isi rilis

- 11 KF Must/Should berfungsi: KF-01–KF-11.
- KF-12 (salin struk WhatsApp) tidak termasuk (Could).
- 119 uji otomatis + skrip skema (angka final diperbarui setelah eksekusi rilis).
- Dokumentasi desain, pengujian, manual, deployment, dan UAT templates.
- Screenshot manual tersedia di `docs/gambar/`.

## Cara menjalankan

```bash
bun install
copy .env.example .env
# isi SECRET_KEY
bun run buat:pengguna
bun start
```

Health check: `GET /kesehatan` → `{"status":"ok","versi":"1.0.0"}`.

## Perintah rilis (dijalankan pengguna)

```bash
git switch main
git pull

git add .

# buka PR, review, merge
git switch main
```

Buat GitHub Release dari tag `v1.0.0` dengan catatan ini. **Agen tidak membuat commit/tag/push.**

## Keterbatasan dan risiko

- KF-12 belum ada.
- Rate limit login in-memory; reset saat restart.
- UAT/deployment/peer review bergantung pada sesi manual.
- Aplikasi satu instance; jangan menjalankan dua proses dengan DB yang sama.
- `COOKIE_SECURE=0` hanya untuk LAN HTTP; gunakan HTTPS untuk akses internet.
